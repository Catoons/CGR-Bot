# CGR Bot

Reminds patrons in the CGR discord when they can submit a review request and automatically pins google doc links along with other shenanigans. Made with the help of ChatGPT so it's kinda jank.

**User commands** 

!ping_cgr_bot - Bot will respond if it is active

!start_reminder [user] - Starts the 6mo timer for the @user

!cancel_reminder [user] - Cancels the 6mo reminder for the @user

!view_reminders - See all active reminders for each user

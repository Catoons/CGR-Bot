# CGR Bot

Reminds patrons in the CGR discord when they can submit a review request along with other shenanigans.
Made with the "help" of ChatGPT so it's kinda jank and probably still has bugs. 

**User commands** 

!ping_pusher - Bot will respond if it is active

!start_reminder [user] - Starts the 6mo timer for the @user

!cancel_reminder [user] - Cancels the 6mo reminder for the @user
